Wok Rush — Dapur Kilat is a fast-paced wok-station cooking game: grab ingredients from the pantry, chop them on the board, fry them in the wok before they burn, plate the dish and serve it to the order window before the customer's patience runs out.

## Run it

```sh
node main.ts
```
Then open game/index.html in a desktop browser (or the built output as the kit rules say).
